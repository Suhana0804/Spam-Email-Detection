# Email Classifier

This project is a GUI based Email Classifier created using Python and Tkinter.

The application analyzes email text files and classifies them into categories such as:
- Important
- Promotional
- Spam

The classifier uses keyword matching, text preprocessing, and scoring logic to identify the type of email.

The project was created to learn:
- Text processing
- File handling
- GUI development
- Email classification logic
- Regular expressions
- Data organization

## Features

- GUI based email classifier
- Email text file loading
- Spam keyword detection
- Promotional email detection
- Important email detection
- Text preprocessing
- Folder selection system
- File navigation system
- Shuffle functionality
- Result display with matching keywords

## Technologies Used

- Python
- Tkinter
- Regex
- CSV
- File Handling

## How It Works

The program:
1. Loads email text files from a folder
2. Cleans and preprocesses the text
3. Searches for spam, promotional, and important keywords
4. Calculates classification scores
5. Displays the predicted email category
